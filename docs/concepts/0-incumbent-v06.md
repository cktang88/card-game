# Incumbent: v0.6 "Battle Line" (honest critique)

The current game, judged against the target experience by the same standard as the new pitches.

**Core:** 7 columns × Front/Back rows. Hidden simultaneous placement, then automatic resolution in 5 steps
(Reveal → Breach/Flank → Edge (column hands) → Strike → Fallout/Upkeep). Nerve 0 means the unit routs,
and every rout costs Resolve. Escalate/Retreat stakes.

**Rule count:** 7 phase steps, about 12 core rules (placement, stacking, Back needs Front, breach,
flank, column hands/Edge, strike targeting, rear bonus, terrain, cohesion, panic, breach drain, underdog,
stakes), about 30 keywords and 9 faction rules. **That's well over the ~10 budget.**

## Where it delivers
- Hidden simultaneous placement exists, and the steelman AI beats the greedy one 82% of the time, so skill matters.
- Morale is the main loss source (56–60%), and games last 6–8 rounds.
- Factions have recognisable verbs (hold / flood / cloak).

## Where it fails the target experience
1. **Readable cause → effect: weak.** One column's result depends on flanks from neighbouring columns, the Edge from
   comparing hands, terrain, cohesion, rear bonus, ambush and auras. A player can't predict a strike value without
   adding up 6–8 modifiers. That fails Into the Breach's "you can see what will happen" test.
2. **Tension at reveal: diluted.** All 7 columns resolve at once, so the reveal is a wall of small numbers rather
   than one or two decisive moments.
3. **Lead changes are rare** (0.28 per game at baseline). Games drift one way, and the decided round averages 5.7 of 7.
4. **Morale still reads like a second health bar.** Shock lowers Nerve, Nerve 0 means rout. The pieces that make
   it different (panic, cohesion, rout returns the card) are subtle bookkeeping, not dramatic moments.
5. **The gamble (Escalate/Retreat) is bolted on.** It doesn't interact with what you place, and the AI barely uses it.
6. **Grown by accretion.** Hex → lanes → battle line, plus HQ, Hive placement, column hands and cohesion were each
   added to fix a symptom, never reconsidered as a whole.

## What's worth keeping whatever we pick
Faction fantasies and card names/art, hidden simultaneous orders, stacking to reinforce, units don't move,
the steelman AI and sim harness.
